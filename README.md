# Что дешевле

Android-приложение для быстрого сравнения цен на товары, расчёта стоимости единицы измерения и выбора наиболее выгодного предложения.

Пользователь указывает цену и количество товаров, получает стоимость одинакового количества продукта и узнаёт, какой вариант выгоднее. История сравнений и настройки сохраняются локально на устройстве.

Приложение разрабатывается для использования без регистрации, собственного сервера и обязательного подключения к интернету.

## Возможности

### Сравнение цен

- сравнение двух товаров;
- ввод цены и количества каждого товара;
- выбор единицы измерения;
- расчёт стоимости единицы товара;
- отображение более дешёвого товара;
- отображение результата сравнения;
- необязательное название сравнения;
- ввод чисел с точностью до 5 знаков после запятой;
- проверка заполнения и корректности введённых значений.

Текущий список единиц измерения:

- г;
- кг;
- мл;
- л;
- шт.

На текущем этапе используется одна общая единица измерения для обоих товаров. Автоматическое сравнение товаров с разными единицами измерения запланировано на будущее.

### История сравнений

История хранится локально на устройстве.

Доступно:

- сохранение результатов сравнений;
- хранение до 50 последних записей;
- сохранение даты и времени сравнения;
- восстановление сравнения из истории;
- удаление отдельной записи;
- очистка всей истории с подтверждением;
- группировка записей по дням.

Название сравнения необязательно.

### Бензин

Отдельный экран для расчёта необходимого количества топлива:

- указание объёма топливного бака;
- указание текущей заполненности бака в процентах;
- расчёт количества литров, необходимых для заполнения бака до 100%;
- сохранение объёма топливного бака по умолчанию.

### Настройки

- сохранение единицы измерения по умолчанию;
- сохранение объёма топливного бака по умолчанию;
- переключение темы оформления;
- локальное хранение настроек.

## Технологии

- Jetpack Compose;

- Android SDK;
- SharedPreferences;
- JSON.

## Хранение данных

На текущем этапе приложение использует локальное хранение данных без собственного сервера и облачной синхронизации.

- История сравнений хранится в SharedPreferences в формате JSON.
- Настройки сохраняются локально на устройстве.
- История ограничена 50 последними записями.

Переход на Room (SQLite) запланирован на следующий этап развития приложения. Перед переходом необходимо предусмотреть перенос уже сохранённой истории, чтобы существующие записи не потерялись.

## План дальнейшего развития

### Этап 1. Развитие текущей версии

Продолжить тестирование приложения без внедрения Room и без сервера.

Приоритеты:

- проверить корректность расчётов;
- проверить сохранение и восстановление истории;
- проверить работу настроек;
- уточнить удобство интерфейса на реальных сценариях покупок.

### Этап 2. Единицы измерения

Предусмотреть расширяемый список единиц измерения.

Планируемые возможности:

- добавление новых единиц измерения;
- редактирование существующих единиц без создания новой записи;
- ручная сортировка единиц;
- добавление новых единиц в конец списка;
- сохранение порядка отображения;
- единый порядок единиц во всех соответствующих списках приложения.

При удалении единицы порядок оставшихся единиц должен сохраняться без пропусков.

При сравнении товаров с разными единицами измерения необходимо проверять их совместимость. Например, граммы и килограммы можно сопоставлять после пересчёта, а граммы и миллилитры нельзя напрямую сравнивать без дополнительных сведений о продукте.

История должна сохранять исходное обозначение единицы измерения, использованное при сравнении.

### Этап 3. Отложенные сравнения

Реализовать возможность сохранить данные одного товара и вернуться к сравнению позже, когда будет найден второй товар.

Пример использования:

1. Покупатель находит товар в первом магазине: 450 мл за 300 ₽.
2. Сохраняет его для отложенного сравнения.
3. Позже находит аналогичный товар в другом магазине: 900 мл за 500 ₽.
4. Открывает сохранённую запись, добавляет второй товар и запускает сравнение.
5. Приложение рассчитывает стоимость одинакового количества продукта и показывает более выгодный вариант.

Требования:

- сохранение отложенных сравнений между запусками приложения;
- возможность вести несколько отложенных сравнений одновременно;
- возможность добавить второй товар позднее;
- возможность редактировать и удалять записи;
- необязательные названия товаров и сравнений;
- необязательное указание магазина для каждого товара;
- сохранение цены, количества, единицы измерения и даты внесения данных;
- возможность завершить сравнение и сохранить результат в истории;
- отсутствие автоматического удаления незавершённых сравнений без подтверждения пользователя.

Отложенные сравнения должны работать локально, без регистрации и сервера.

### Этап 4. Переход на Room

После проверки текущего функционала перейти на локальную базу данных Room (SQLite).

Предварительно планируются следующие сущности:

- история завершённых сравнений;
- отложенные сравнения;
- товары в составе сравнений;
- единицы измерения;
- магазины;
- настройки приложения.

Перед внедрением необходимо определить окончательную структуру данных и связи между сущностями.

При переходе следует перенести существующую историю из SharedPreferences в новую базу данных и проверить сохранность записей.

### Этап 5. Дополнительные возможности

После реализации основных этапов можно рассмотреть:

- поиск и фильтрацию истории;
- повторное сравнение ранее сохранённых товаров;
- экспорт и резервное копирование данных;
- дополнительные инструменты для сравнения покупок.
