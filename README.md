# Что дешевле

Android-приложение для быстрого сравнения цен на товары.

Пользователь указывает цену и количество двух товаров, выбирает единицу измерения и получает стоимость одной единицы. Результаты сравнений сохраняются локально на устройстве.

## Возможности

### Сравнение цен

- сравнение двух товаров;
- ввод цены и количества;
- единицы измерения:
    - г;
    - кг;
    - мл;
    - л;
    - шт;
- расчёт цены за выбранную единицу;
- подсветка более дешёвого товара;
- название сравнения, необязательно;
- ввод чисел с точностью до 5 знаков после запятой.

### История

История хранится локально на устройстве.

Доступно:

- сохранение результатов сравнений;
- до 50 последних записей;
- дата и время сравнения;
- восстановление сравнения из истории;
- удаление отдельной записи;
- очистка всей истории с подтверждением.

### Бензин

Отдельный экран для расчёта необходимого количества топлива:

- объём бака;
- текущая заполненность бака в процентах;
- расчёт количества литров для заправки.

## Технологии

- Kotlin
- Jetpack Compose
- Material 3
- Android SDK
- SharedPreferences
- JSON

## Архитектура хранения

На текущем этапе приложение работает полностью локально.

История сравнений хранится в `SharedPreferences` в формате JSON.

Серверная часть и синхронизация не используются.
