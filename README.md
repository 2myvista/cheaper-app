# Что дешевле

Android-приложение для быстрого сравнения цен на товары и расчёта стоимости единицы измерения.

Пользователь указывает цену и количество двух товаров, выбирает единицу измерения и получает результат сравнения. История сравнений и настройки сохраняются локально на устройстве.

## Возможности

### Сравнение цен

- сравнение двух товаров;
- ввод цены и количества;
- единицы измерения:
  - г;
  - кг;
  - мл;
  - л;
  - шт;
- расчёт цены за выбранную единицу;
- отображение более дешёвого товара;
- необязательное название сравнения;
- ввод чисел с точностью до 5 знаков после запятой.

### История сравнений

История хранится локально на устройстве.

Доступно:

- сохранение результатов сравнений;
- хранение до 50 последних записей;
- дата и время сравнения;
- восстановление сравнения из истории;
- удаление отдельной записи;
- очистка всей истории с подтверждением.

### Бензин

Отдельный экран для расчёта необходимого количества топлива:

- указание объёма бака;
- указание текущей заполненности бака в процентах;
- расчёт количества литров, необходимых для заполнения бака до 100%.

### Настройки

- сохранение единицы измерения по умолчанию;
- сохранение объёма топливного бака по умолчанию;
- локальное хранение настроек.

## Технологии

- Kotlin;
- Jetpack Compose;
- Material 3;
- Android SDK;
- Room;
- SharedPreferences;
- JSON;
- SQLCipher for Android;
- Android Keystore.

## Хранение данных

Приложение работает локально, без собственного сервера и синхронизации с облаком.

- История сравнений хранится в `SharedPreferences` в формате JSON.
- Настройки хранятся в локальной базе данных Room.
- Для шифрования базы данных используется SQLCipher for Android.
- Ключ шифрования защищается с помощью Android Keystore.

## Структура проекта

Основной код приложения находится в `app/src/main/java/ru/myvista/cheaper/`.

В проекте используются отдельные файлы для экранов, хранения истории и других компонентов приложения.
